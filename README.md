# SciReliGraph — epistemic contracts for scientific agent tools

Reproducibility package for **"Can Agents Trust a Replication Verifier? Epistemic Contracts for Scientific Agent Tools"**
(Luxin Zhang, Independent Researcher; submitted to SE4AgenticAI 2026, the 2nd IEEE Big Data Workshop on Software Engineering for Agentic AI).

The paper specifies an *epistemic contract* for a claim-verifier tool (temporal validity, label isolation, decision-relevant
output, auditability), implements it as an MCP tool, tests it with metamorphic/isolation tests and mutation analysis, and
evaluates it on the 274 SCORE replication outcomes and with LLM judges and LLM agents in the loop.

## Contents
| Path | What |
|---|---|
| `src/` | Data acquisition, dataset build with label gate, experiments, verifier library (`verifier.py`), MCP server (`mcp_server.py`), LLM-judge and agent experiments, mutation tooling, table/number/figure generators, citation checker |
| `tests/` | 26 contract, schema and boundary tests |
| `contract/` | Reusable JSON-Schema specification of an epistemic-contract response, with tool-agnostic test relations |
| `data/processed/` | Claim table, graph features, provenance manifest (source archive SHA-256, access dates) |
| `results/` | All metrics, out-of-fold predictions, cached LLM-judge and agent responses, mutation analysis, `citation_check.md` |
| `paper/` | LaTeX source and PDF. Every number in the prose is a macro in `paper/tables/numbers.tex`, generated by `src/make_numbers.py` |
| `baseline/` | The original starter baseline |

Not included (re-downloadable by the scripts): the raw SCORE analyst package (OSF g5sny, CC0; SHA-256 in
`data/processed/manifest.json`) and the OpenAlex cache (`src/fetch_openalex.py`).

## Quick start
```bash
python -m venv .venv && .venv/bin/pip install -r requirements.txt
# (run the two download steps below before the tests: they need the SCORE package and the OpenAlex cache)
OMP_NUM_THREADS=1 .venv/bin/python -m pytest -q tests        # 26 contract, schema and boundary tests
.venv/bin/python src/get_score_data.py                        # SCORE package from OSF, SHA-256 checked
.venv/bin/python src/fetch_openalex.py && ./run_all.sh       # full offline pipeline
```
The pre-specified R6 consumability experiment (`src/r6_experiment.py`) was committed before any call was made
(commit `8990cf7`); its cached responses are in `results/r6/` and its analysis in `results/r6_summary.json`.

LLM experiments read `OPENAI_API_KEY` / `ANTHROPIC_API_KEY` from the environment. The cached responses in `results/llm/`
and `results/agent/` let every LLM analysis re-run without API access (`src/llm_analysis.py`, `src/llm_recalibration.py`,
`src/agent_experiment.py analyse`).
